
# SiteGuard 🔐

A lightweight Python tool for basic web security analysis.

## About

SiteGuard is a Python-based project designed to analyze basic web security configurations.

It performs checks related to:

- HTTPS connectivity
- TLS certificate validation
- HTTP security headers
- Certificate expiration

## Technologies

- Python 3
- Socket
- SSL/TLS
- urllib
- Certifi

## Installation

Clone the repository:

```bash
git clone https://github.com/Plovinski/siteguard.git
```

Enter the project directory:

```bash
cd siteguard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the application:

```bash
python siteguard.py
```

Enter a domain when prompted.

## Disclaimer

This project is intended for educational purposes.

Only analyze websites you own or have authorization to test.
